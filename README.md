# GodoziCodes Portfolio

A cinematic black-and-white developer portfolio for Ozioma Onyenwenu.

## Features

- Responsive one-page portfolio
- Custom GodoziCodes cat monogram
- Smooth scroll reveal animations
- Featured TrustPoint case study
- Services and technology stack sections
- Contact and GitHub links
- Installable PWA with offline support

## Deploy

Import this repository into Vercel and use the default static deployment settings. No build command is required.
